# import/

Положите сюда свои файлы (например, `.txt`), и `npm run look` перед запуском QEMU запишет их на диск genesis.
Они попадают в папку `/home` (папка по умолчанию): их видно в `ls` и в «Открыть» на рабочем столе. Файл с тем же именем на диске заменяется.

Ограничения: имя до 31 символа латиницей без пробелов, размер до 1 МБ, всего на диске до 256 файлов и папок.
Если что-то не подходит, файл пропускается, а в консоли пишется причина.
Содержимое папки (кроме этого файла и `.gitkeep`) в git не попадает.
