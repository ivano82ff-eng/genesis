# genesis — полное руководство

genesis — маленькая учебная ОС: своё ядро, оболочка, файловая система Grid Store,
пакеты, компилятор C, защита памяти, TCP/IP, браузер и рабочий стол «Ядро».
Две сборки:

| Сборка | Где работает | Чем отличается |
|---|---|---|
| **x86_64** | QEMU (`qemu-system-x86_64`), `npm start`, `npm run look` | long mode, NX (стек программ не исполняется), диск `build/genesis-disk.img` |
| **i686** | сайт https://ivano82ff-eng.github.io/genesis/ (эмулятор v86), `qemu-system-i386` | 32-битные страницы, без NX, диск хранится в браузере (IndexedDB) |

Если не сказано иное, всё в этом руководстве работает в **обеих** сборках.
Пометки: **[QEMU]** — только в QEMU, **[сайт]** — только на сайте (v86).

Содержание:

## 1. Запуск

### Сайт [сайт]
Откройте **https://ivano82ff-eng.github.io/genesis/** — на компьютере, телефоне,
планшете или телевизоре. Стол «Ядро» откроется сам (на вертикальном экране — 480x800).

- Кнопки справа вверху: **🎮** — экранные кнопки (стрелки, OK, Esc, Tab, ⌫, RU/EN);
  **⌨** — клавиатура телефона; **Вставить** — вставка из буфера обмена; **⛶** — весь экран.
- Параметры адреса: `?shell` — текстовая оболочка без стола; `?size=1280x720` —
  размер стола; `?net=0` — без сети; `?relay=wss://…` — свой сетевой relay.
- Диск (32 МиБ) хранится в браузере и переживает перезагрузку страницы.
  Начать с чистого диска — очистить данные сайта.

### QEMU [QEMU]
Нужны Node.js ≥ 18, NASM, GCC, Binutils, QEMU, GRUB (Ubuntu/WSL):
```
sudo apt install -y build-essential nasm qemu-system-x86 grub-pc-bin grub-common xorriso mtools
npm install
npm run build          # build/genesis.iso
npm run look           # окно QEMU со столом (не закрывается само)
npm run look -- --portrait   # как телефон (480x800)
npm run look -- --tv         # как телевизор (1920x1080)
npm start              # прогон до маркера "genesis: kernel booted", код 0/1
node dist/src/cli.js log --timeout 30   # журнал COM1
npm test               # все тесты x86_64
npm run test:i686      # все тесты i686 (qemu-system-i386)
npm run web            # собрать сайт в web/ (i686 + v86)
node dist/src/cli.js show --arch i686   # i686-образ в окне QEMU
```
С сетью: `qemu-system-x86_64 -cdrom build/genesis.iso -netdev user,id=n0 -device ne2k_pci,netdev=n0`
(или `-device rtl8139,netdev=n0`). Без WSLg `npm run look` запускает QEMU для
Windows (`GENESIS_QEMU` задаёт другой бинарник).

Первая загрузка с CD устанавливает ядро на диск; дальше можно грузиться с диска.
При ошибке старта COM1 пишет `ERR M` (нет Multiboot2), `ERR C` (нет CPUID),
`ERR L` (нет long mode).

## 2. Команды оболочки (полный список)

Приглашение: `genesis:/home>` (текущая папка). Те же команды выполняет строка
внизу рабочего стола. `help` печатает список всех команд.

|---|---|---|
| `help` | список всех команд | `help` |
| `echo [ТЕКСТ]` | печатает текст (с подстановкой `$VAR`) | `echo привет $X` |
| `clear` | очистить экран (на столе — терминал) | `clear` |

| Команда | Что делает | Пример |

| Команда | Что делает | Пример |
|---|---|---|

| Команда | Что делает | Пример |
|---|---|---|

### Программы и задачи
| Команда | Что делает | Пример |
|---|---|---|
| `run ИМЯ [АРГУМЕНТЫ]` | запустить программу (ищет в текущей папке, потом `/bin`) | `run hello`, `run crashy null` |
| `run ФАЙЛ.c` | то же, что `cc ФАЙЛ.c` | `run /docs/fib.c` |

Программы на диске: `hello` (печатает `hello from program`), `ticker` (5 раз `tick`
раз в полсекунды), `pulse` (`pulse` раз в секунду до `kill`), `crashy` (проверка
защиты: `null`, `kernel`, `div`, `op`, `sys`, `loop`), просмотрщики `vtxt`, `vdocx`,
`vimg`, `vpdf`, `vmp4`, `open` (запускаются со стола).

## 3. Возможности оболочки

- **Кавычки:** `"..."` (с подстановкой `$VAR`) и `'...'` (как есть).
- **Переменные:** `ИМЯ=значение`, `$ИМЯ`; `set` — список. До 16 переменных, имя до 15 символов, значение до 63.
- **Несколько команд:** `cmd1; cmd2`. **Комментарий:** `# ...`.
- **Перенаправление:** `> ФАЙЛ` (перезаписать), `>> ФАЙЛ` (дописать).
- **Конвейер:** `cmd1 | cmd2 | …` (до 4 звеньев); фильтры `grep`, `wc`, `head`, `cat`.
- **Фон:** `ИМЯ &` (как `spawn`).
- **Скрипты:** `sh ФАЙЛ` — построчно, можно вложенно.
- **История:** ↑/↓ — 16 последних строк (на столе — PgUp/PgDn или ↑/↓, пока строка не пуста).
- **Дополнение:** Tab — команды для первого слова, пути после него; при нескольких вариантах печатает их.
- Строка — до 127 символов.

```
X=hello; echo "$X world"
echo one > f1; echo two >> f1; cat f1
ls /bin | grep ticker | wc
echo 'echo hi-$X' > s1; sh s1
ticker &
```

## 4. Файловая система Grid Store (GBF2)

- До **256** записей (файлы + папки), файл до **1 МиБ**, путь до 63 символов, имя до 31.
- Диск 32 МиБ: [QEMU] сырой образ `build/genesis-disk.img` (без FAT), [сайт] IndexedDB.
- Раскладка: `/bin` — программы, `/lib` — библиотеки `pkg`, `/docs` — примеры, `/home` — ваши файлы (папка по умолчанию).
- Пути абсолютные и относительные, с `.` и `..`.
- Встроенные файлы: `/home/readme`, `/home/notes.txt`; `/docs/note.txt`, `note.docx`, `note.pdf`, `pic.png`, `pic.jpg`, `clip.mp4`, `hello.c`, `fib.c`, `index.html`, `web.html`.
- Служебные (скрытые): `/home/.journal` (Лента), `/home/.pins` (закреплённые папки), `/home/.layout` (ячейки); `/home/inbox/` — файлы от соседа.
- **Папка импорта** [QEMU]: файлы из `import/` в проекте при сборке попадают в `/home`.
- Старый плоский диск `GBF1` переводится автоматически.

## 5. Редактор `edit`

`edit ФАЙЛ` (или сота «Редактор» — `/home/readme`). Если файла нет — создаётся при сохранении.

| Клавиши | Действие |
|---|---|
| стрелки, Home/End, PgUp/PgDn | курсор |
| Enter | разбить строку |
| Backspace / Delete | удалить символ (по символам UTF-8) |
| Tab | 4 пробела |
| Shift+стрелки | выделить |
| Ctrl+C / Ctrl+X / Ctrl+V | копировать / вырезать / вставить (без выделения — вся строка) |
| Ctrl+S | сохранить (до 64 КиБ) |
| Ctrl+Q или Esc | выход (с несохранёнными правками — нажать ещё раз) |
| Ctrl+Пробел, Alt+Shift | RU/EN |

Строка состояния: имя, `[+]` при изменениях, `Ln:Col`, RU/EN. Подсветка: `.c/.h`, `.asm/.s`, `.sh`.

## 6. Вставка текста

- [сайт] **Ctrl+V** или **Shift+Insert** вставляет буфер обмена компьютера (переводы строк, табы, кириллица); на телефоне — кнопка «Вставить» или долгое нажатие в поле ⌨.
- [QEMU] общего буфера нет: положите файл в `import/` или наберите.
- Внутри genesis: в редакторе Ctrl+C/X/V; в терминале Ctrl+V вставляет внутренний буфер в строку.

## 7. Задачи и программы

- Таймер 100 Гц переключает задачи по кругу; до 4 задач (0 — оболочка).
- Программа вызывается как `prog(print, sleep, sym)`; `sleep(n)` — n тиков.
- `run` держит оболочку до конца программы; вечные программы — через `spawn`.
- Сбой программы останавливает только её (§10); на столе ядро краснеет, в Ленте — красная карточка.

## 8. Пакеты `pkg`

Репозиторий вшит в образ (папка `packages/` проекта, на диске места не занимает до установки).

| Пакет | Тип | Зависит от | Что |
|---|---|---|---|
| `mathlib` | библиотека | — | pow, gcd, isqrt, udivmod |
| `strlib` | библиотека | mathlib | len, upper, reverse, utoa |
| `strdemo` | программа | strlib | пример вызова библиотек |

```

```
Программы ставятся в `/bin` (и получают соту на столе), библиотеки — в `/lib`.
Связывание при запуске: `sym(lib, name)` даёт адрес функции или 0. Версии только
информационные; перед установкой проверяется место.

## 9. Компилятор C `cc`

`cc ФАЙЛ.c` (или `run ФАЙЛ.c`) компилирует в байт-код и сразу запускает в песочнице:
каждое обращение к памяти проверяется, бесконечный цикл останавливается.

- **Язык:** `int`, `char`, `void`, указатели, массивы (глобальные и локальные), функции
  (рекурсия, любой порядок), `if/else`, `while`, `do/while`, `for`, `break`, `continue`,
  `return`, `sizeof`, приведения, `?:`, все обычные операторы, `+=` и т. п., `++/--`,
  строковые и символьные литералы, глобальные инициализаторы-константы.
- **Библиотека:** `printf` (`%d %i %u %x %c %s %%`, ширина, `0`), `putchar`, `puts`,
  `malloc`, `free`, `strlen`, `strcmp`, `strcpy`, `memset`, `exit`,
  `tcp_connect`, `tcp_send`, `tcp_recv`, `tcp_close`.
- **Нет:** `struct`, `float`, `switch`, препроцессора (строки `#` пропускаются).
- **Пределы:** исходник до 64 КиБ, код до 32768 слов, память программы 512 КиБ, стек 64 КиБ, до 1024 имён.

```c
int fib(int n) { return n < 2 ? n : fib(n - 1) + fib(n - 2); }
int main() {
    int i;
    for (i = 0; i < 10; i++) printf("%d ", fib(i));
    printf("\n");
    return 0;
}
```
`edit /home/my.c` → Ctrl+S → `cc /home/my.c`. Примеры: `cc /docs/hello.c`, `cc /docs/fib.c`.

## 10. Защита памяти

- Программы (`run`, `spawn`, `&`) — в кольце 3, каждая в своём адресном пространстве.
  x86_64: код с `0x8000010000`, стек под `0x8000800000`, библиотеки с `0x8000400000`.
- Системные вызовы — `int 0x80`; ядро проверяет каждый указатель.
- Сбой (page fault, GPF, деление на 0, неверная инструкция) останавливает только задачу:
  `task 1 (crashy): page fault … - task stopped, system OK`. Сбой ядра — `KERNEL PANIC`.
- Память задачи возвращается при выходе/сбое/`kill`.
- **x86_64:** стек без права исполнения (NX). **i686:** без NX, страницы 4 МиБ (ядро) / 4 КиБ (программы).
- Ограничения: просмотрщики пока в кольце 0; библиотеки отображаются с правом записи; SSE между задачами не сохраняется.

```
run crashy null; run crashy kernel; run crashy div; run crashy op; run crashy sys
spawn crashy loop; ps; kill 1; mem
```

## 11. Сеть TCP/IP

Карты RTL8139 и NE2000 (PCI). Стек без прерываний: ARP, IPv4, ICMP, UDP, DHCP, DNS, TCP.

- [QEMU] `-netdev user` → `dhcp` даёт 10.0.2.15, хост — 10.0.2.2, DNS — 10.0.2.3.
- [сайт] NE2000 включена сама, роутер v86 — 192.168.86.1. HTTP идёт через `fetch()`
  браузера: только порт 80 и только сайты с CORS; `http://ПОРТ.external/` — `localhost:ПОРТ`
  компьютера. `ping` — только до роутера, `nc`/`udp` наружу не ходят (без relay).

**C API** (в `cc`):
```c
int s = tcp_connect("10.0.2.2", 8000);   // < 0 — ошибка
tcp_send(s, "GET / HTTP/1.0\r\n\r\n", 18);
char buf[512]; int n = tcp_recv(s, buf, 511);   // 0 — закрыто; ждёт до 3 с
tcp_close(s);
```
Ограничения: TCP без окна и без сборки сегментов не по порядку; нет HTTPS/TLS.

## 12. Браузер

Сота «Браузер» (глобус), `browse АДРЕС` или `.html` из «Файлов».

- **Адреса:** `http://хост[:порт]/путь` (`https://` идёт как http), файлы с диска
  (`/docs/index.html`, `file:///docs/web.html`; папка — список ссылок), `about:home`,
  `about:help`, `about:blank`; `example.com` без схемы — как `http://`.
- **HTML:** `h1–h6`, `p`, `br`, `ul/ol/li`, `a`, `pre`, `hr`, `img alt`, `td`, `title`,
  сущности; `script`, `style`, `svg`, `template`, `select`, `iframe` и комментарии выбрасываются.
- **Управление:** щелчок/касание по ссылке; Tab/стрелки — по ссылкам, Enter — открыть;
  без фокуса ↑/↓ и PgUp/PgDn — прокрутка, кнопки ^/v; «Обновить»; щелчок по адресу —
  он в строке внизу; новый адрес — набрать внизу + Enter.
- **Назад** (Backspace, «<», «< Назад») — ровно одна страница; на первой — закрыть окно.
  **Esc**/X — закрыть сразу.
- Ошибки (нет сети, файла, 404, отказ соединения) — страница «Страница не открылась».
- Пределы: до 5 переадресаций, история 16 страниц, 500 строк, 160 ссылок, адрес до 255 символов; только UTF-8; без CSS/JS.

---

## 13. Genesis Link (сосед) [QEMU]

Свой протокол поверх Ethernet (ethertype `0x88B5`, заголовок `G` `L`, версия, тип, длина,
контрольная сумма): ping/pong, текст, файлы. Два гостя соединяются сокетной сетью QEMU
(`-netdev socket,listen=…` / `connect=…`).

- `ping` → `pong`; `say ТЕКСТ` → `link: ТЕКСТ` у соседа; `send ФАЙЛ` → `/home/inbox/` соседа
  (куски по 112 байт с подтверждением и контрольной суммой).
- На столе ответивший сосед — маленькое ядро «СОСЕД»; щелчок/Enter — выбрать файл в /home для отправки.

## 14. Рабочий стол «Ядро»

`desktop` (на сайте открывается сам).

- **Ядро** (шестиугольник в центре): память и число фоновых задач, раз в секунду;
  краснеет при куче > 85% и на 3 с при сбое программы. Щелчок — «Задачи» с кнопкой «стоп».
- **Соты** вокруг: Файлы, Редактор, Терминал, Пакеты, Память, Лента, Настройки, Браузер,
  затем установленные программы и закреплённые папки (до 12). Альбомный экран — кольцо;
  телефон — ядро сверху, соты сотами снизу.
- **Строка команд** внизу: любая команда, подсветка подходящей соты, Tab, история; ответ — под строкой и в «Терминале».
- **Окна (панели):** справа (альбомный экран), Лента и Браузер — на всю ширину, на телефоне — весь экран с «< Назад».
  - Файлы: папки, «.. Назад», Выше/Ниже, щелчок по файлу — просмотрщик по расширению (`txt`, `docx`, `png/jpg`, `pdf`, `mp4`), `.html` — браузер.
  - Терминал, Пакеты (Установить/Удалить), Память, Настройки (Раскладка, Перезагрузка, Выключить, Ячейки: правка), Задачи.
  - Кнопка «В ленту» — Лента с фильтром этой панели.
- **Правило Назад/Esc:** Назад (Backspace, «<», «< Назад», кнопка просмотрщика) — ровно один шаг назад
  внутри окна (папка, страница, фильтр); когда шагов нет — закрыть окно. **Esc** или **X** — закрыть окно сразу.
- **Лента:** журнал действий (`/home/.journal`, последние 40): команды, файлы, пакеты, запуск/остановка/сбой
  программ. Карточки на линии времени с отметкой «Сейчас»; фильтры Все/Файлы/Редактор/Терминал/Пакеты/Программы;
  Enter — открыть снова или повторить; опасные команды (`rm`, `rmdir`, `mv`, `write`, `pkg remove`, `kill`, `unpin`,
  `reboot`, `poweroff`) — второй Enter, Esc — отмена.
- **Связи:** когда программа берёт функцию из библиотеки, вспыхивает линия к соте «Пакеты»; пока программа работает — к ядру.
- **Часы:** CMOS RTC, пояс `tz`.
- **Ячейки (layout):** порядок и набор в `/home/.layout` (ключ в строке, `-ключ` — скрыта), восстанавливается при загрузке.
  Ключи: `files editor term pkg mem feed set web`, `app:ИМЯ`, `pin:/ПАПКА`.
  - Правка: «Настройки» → «Ячейки: правка», `layout edit` или долгое нажатие (~0,6 с) на соту. Соты янтарные.
    Мышь/касание — перетащить на место другой; клавиатура/пульт — выбрать, Enter взять, стрелки двигать,
    Enter положить, `x` — убрать; Esc, Backspace или щелчок по ядру — готово.
  - Команды: `layout` / `layout list`, `layout move ИМЯ ПОЗ` (с 1), `layout remove ИМЯ`,
    `layout add ИМЯ` (вернуть; `/папка` — закрепить), `layout reset`, `layout edit`. ИМЯ — ключ или подпись.

## 15. Управление

| Действие | Клавиатура | Мышь / касание | Пульт ТВ / 🎮 |
|---|---|---|---|
| выбрать соту/кнопку | стрелки, Tab | наведение | стрелки |
| открыть | Enter | щелчок / касание (по отпусканию) | OK |
| шаг назад | Backspace | «<» / «< Назад» | ⌫ / Back |
| закрыть окно | Esc | X | Esc |
| прокрутка | ↑/↓, PgUp/PgDn | Выше/Ниже, ^/v | стрелки |
| правка сот | `layout edit` | долгое нажатие, перетаскивание | Enter + стрелки |
| раскладка RU/EN | Ctrl+Пробел, Alt+Shift | «Настройки» → Раскладка | RU/EN |

Первая стрелка ставит фокус на ядро. В панели фокус на первой строке; ←/→ выходят к сотам и обратно.
QEMU на Windows шлёт стрелки как цифровой блок без NumLock — тоже работает.
В текстовой оболочке: ↑/↓ — история, Tab — дополнение.

## 16. Русский язык

Всё UTF-8. Ctrl+Пробел или Alt+Shift — Latin / ЙЦУКЕН (индикатор RU/EN). Шрифт с кириллицей,
Ё/ё, « », —, №; в текстовом режиме VGA глифы загружаются в шрифт карты.

## 17. Ограничения (сводка)

- Файлов+папок 256, файл 1 МиБ, путь 63, имя 31; редактор и `cc` — до 64 КиБ.
- Куча ядра 1 МиБ; задач 4 (оболочка + 3); переменных 16; строка 127; история 16; Лента 40.
- Соты до 12. `layout add` — только известные соты или папка.
- Сеть: нет TLS; TCP упрощённый; [сайт] только HTTP:80 с CORS.
- C: нет `struct`, `float`, `switch`, препроцессора.
- Браузер: нет CSS/JS, 5 переадресаций, 16 страниц истории.
- Genesis Link — только между гостями QEMU.
- i686: нет NX. Просмотрщики в кольце 0.
